Etiqueta em forma de pílula para categoria ou estado de um item.

Você fornece o rótulo (`children`), de uma ou duas palavras, e a `variant`.

- `roxo` é o padrão; `magenta` chama atenção para algo novo ou urgente; `solido` marca o item selecionado.
- A etiqueta informa, não é clicável. Para ações, use Button.
- A cor nunca é o único sinal: o rótulo sempre diz o estado por extenso (“Encerrado”, “Em breve”).
