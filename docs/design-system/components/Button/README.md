Botão para a ação principal ou secundária de uma tela.

Você fornece o rótulo (`children`), a `variant`, o `size` e o `onClick`, ou um `href` para virar link.

- Use um único `primary` por tela; as demais ações em `secondary`.
- `accent` (magenta) é para a chamada mais importante de uma campanha, como “Doe agora”. Não use dois na mesma tela.
- Rótulos são verbos curtos: “Participe”, “Fale com a gente”.
- O texto do `accent` é `roxo-escuro`: branco sobre `magenta` não tem contraste para texto pequeno.
- Sobre fundo `roxo`, use `accent` ou `secondary`; o `primary` some.
- O anel de foco é `roxo-escuro`, 3px, pensado para fundos claros.
