Cartão para agrupar um título, um texto curto e ações sobre um mesmo assunto.

Você fornece `title`, o texto (`children`) e, se quiser, `eyebrow` (data ou categoria) e `footer` (botões ou etiquetas). A largura vem do contêiner onde o cartão está.

- `default` sobre fundo `branco`; `tint` para diferenciar um grupo sem borda; `destaque` (roxo cheio) para um único cartão por seção.
- Dentro de `destaque`, use Button `accent` ou `secondary`, nunca `primary`.
- Mantenha o texto em duas ou três linhas; conteúdo longo pede uma página.
- Sem sombra: o cartão se separa do fundo por `borda` ou por cor.
