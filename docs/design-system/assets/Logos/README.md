Arquivos originais do logo do Instituto VOSZ, em quatro arranjos (horizontal, empilhado, vertical, símbolo) mais o nome sozinho (wordmark).

- `-cor`: roxo `#4200ac` com magenta `#ff00a7`, fundo transparente. Para fundos `branco` e `roxo-claro`.
- `-negativo`: branco com magenta, fundo transparente. Para fundos `roxo` e `roxo-escuro`. Parece vazio sobre branco.
- `-branco`: todo branco, fundo transparente. Para fotos e fundos coloridos. Invisível sobre branco.
- `-preto`: todo preto. Para impressão em uma cor.
- `-fundo-roxo`: a versão negativa já aplicada sobre um quadrado `roxo`. Para avatares e redes sociais.

São imagens (PNG e WebP), não vetores: não amplie além do tamanho original.
